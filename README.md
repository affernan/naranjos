# Los Naranjo de Telde

Web de la investigación genealógica sobre Félix Naranjo Cabrera (Telde, 1843), Rosalía Rodríguez Valdés y sus descendientes en Cuba, y sobre los hermanos de Félix en Venezuela.

- Todo el contenido (personas, documentos y textos) está en `_construir.py`. Para modificar algo, edita ese archivo y ejecuta `python _construir.py`: se regeneran todas las páginas `.html`.
- Las imágenes están en `img/`:
  - `docs/`: certificados y actas;
  - `prensa/`: recortes y páginas completas;
  - `fotos/`: retratos;
  - `escudo-naranjo.png`.
- Solo se publican personas fallecidas.
